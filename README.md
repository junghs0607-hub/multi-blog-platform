# DOMINO X - 통합 자산관리 & 배당 플랫폼

주식 투자관리 앱 「도미노(Domino)」 스타일의 **웹 기반 올인원 통합 자산관리 서비스**입니다.

## 🚀 주요 기능

1. **전체 자산 관리 (Executive Dashboard)**
   - 통합 순자산 (Net Worth), 총자산, 총매입금액, 평가금액, 실현/미실현 손익, 총 수익률
   - 프라이버시 모드 (금액 숨김/표시 `•••••• 원`)
   - 다각도 자산배분 차트 (자산군, 국가, 통화, 위험도, 인컴/성장형)
   - 순자산 성장 추이 타임라인 차트 (1W, 1M, 3M, 6M, 1Y, ALL)
   - 실시간 LIVE 시세 틱 시뮬레이션 엔진

2. **11개 자산군 통합 지원**
   - **국내주식**: KOSPI/KOSDAQ 실시간 시세, PER/PBR/EPS/ROE, 52주 고저, 분기 배당
   - **해외주식 (미국)**: USD 및 KRW 동시 표시, 환율 손익 분해
   - **ETF & 커버드콜**: 고배당 커버드콜(JEPI, JEPQ) 별도 태깅, 분배금/분배율 일정
   - **가상자산**: BTC, ETH, SOL, XRP 등 24시간 시세, 실시간 김치 프리미엄 계산기, 거래소별 자산 및 이동 기록, 스테이킹 보상 관리
   - **부동산**: 아파트, 오피스텔, 빌라, 상가 실거래가, 주택담보대출, 임대보증금 및 월세 순현금흐름 계산, 실질 순자산(Equity)
   - **펀드 / 채권**: 국채 10년, 회사채 확정 이자 스케줄, TDF 펀드
   - **현금 및 외화 (FX)**: 원화, 달러, 엔화, 유로 환율 및 환차익 관리
   - **금 / 원자재**: KRX 금현물(1g), 은, WTI 원유 선물

3. **배당 및 분배금 허브 (`/dividends`)**
   - 연간/월평균 예상 배당금, 1월~12월 인터랙티브 배당 캘린더, 월배당/분기배당 필터
   - 배당 재투자 복리 스노우볼 시뮬레이터

4. **통합 거래내역 원장 (`/transactions`)**
   - 매수, 매도, 입금, 출금, 배당금, 월세, 이자, 스테이킹, 환전, 자산이동 다중 필터

5. **포트폴리오 분석 & 리밸런싱 (`/portfolio`)**
   - 목표 비중 설정 시 자동 매수/매도 필요 금액 산출

6. **종목 비교 분석실 (`/compare`)**
   - 2~4개 종목 100% 기준 정규화 수익률 비교 차트 및 재무 지표 맞비교

7. **성과 분석, 현금흐름 & FIRE 플래너 (`/analytics`, `/cashflow`)**
   - TWR/MWR 수익률, 월별 수익률 히트맵 그리드, YoC(투자원금 배당률)
   - FIRE 조기은퇴 게이지 및 경제적 자유 달성도 측정

8. **세금 관리 & 절세 시뮬레이터 (`/taxes`)**
   - 해외주식 양도소득세 (250만 공제 + 22%) 및 손실확정 절세 매매
   - 금융소득종합과세 2,000만원 모니터링 경고 게이지
   - 연금저축/IRP 세액공제 환급 계산기 (최대 900만원)

9. **AI 자산 어드바이저 (`/ai-advisor`)**
   - 포트폴리오 건전성 스코어 (0-100점), 실시간 대화형 AI 금융 챗봇

10. **관심종목, 캘린더, 다중 계좌, 관리자 & 데이터 I/O**
    - 관심종목 스파크라인 시세판 (`/watchlist`)
    - 투자 & 경제 캘린더 (`/calendar`)
    - 다중 금융계좌 관리 (`/accounts`)
    - CSV 가져오기 & JSON 전체 백업 (`/data-io`)
    - 관리자 포털 (`/admin`)

## 🛠️ 기술 스택
- **Framework**: Next.js 16 (App Router) + React 19
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript
- **Deployment**: Node.js / Docker
