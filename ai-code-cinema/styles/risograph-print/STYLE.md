# Risograph Print (리소그래프 인쇄)

- 카테고리: 인쇄 및 판화
- 렌더러: `risograph_print`

## 색상 팔레트

- 배경: #F4F1EA / #E5DCC8
- 전경: #222222
- 강조: #FF48B0, #0078BF

## 배경 표현

재생지 배경

## 재질과 질감

- 질감: riso

## 선과 윤곽선

거친 인쇄 가장자리

## 조명과 그림자

플랫 + 오등록

## 피사체 표현 방식

2~3도 분판 그래픽

## 카메라 움직임

- 기본 움직임: pan

## 애니메이션 특성

- 스텝 모션: 부드러운 모션

## 장면 전환

- 기본 전환: cut

## 화면 구성

- 텍스트 배치: in-scene

## 텍스트 표현

- 자막/화면 텍스트는 `in-scene` 위치에 배치한다.

## 효과음 특성

- 프로필: pop

## 음악 분위기

- 기본 무드: playful

## 금지할 시각적 표현

풀컬러 사진, 부드러운 그라데이션

## 최소 구현

`core/render_py.py`의 `risograph_print` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
