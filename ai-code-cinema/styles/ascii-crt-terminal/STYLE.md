# ASCII / CRT Terminal (ASCII CRT 터미널)

- 카테고리: 그래픽 및 타이포그래피
- 렌더러: `ascii_crt_terminal`

## 색상 팔레트

- 배경: #0A0F0A / #050805
- 전경: #33FF66
- 강조: #33FF66, #FFB000

## 배경 표현

검은 CRT 화면

## 재질과 질감

- 질감: scanline

## 선과 윤곽선

문자 셀

## 조명과 그림자

형광 발광

## 피사체 표현 방식

ASCII 아트 장면

## 카메라 움직임

- 기본 움직임: pan

## 애니메이션 특성

- 스텝 모션: 10fps

## 장면 전환

- 기본 전환: cut

## 화면 구성

- 텍스트 배치: in-scene

## 텍스트 표현

- 자막/화면 텍스트는 `in-scene` 위치에 배치한다.

## 효과음 특성

- 프로필: retro

## 음악 분위기

- 기본 무드: dark

## 금지할 시각적 표현

부드러운 곡선, 사진, 파스텔

## 최소 구현

`core/render_py.py`의 `ascii_crt_terminal` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
