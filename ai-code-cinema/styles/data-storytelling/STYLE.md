# Data Storytelling (데이터 스토리텔링)

- 카테고리: 정보 전달 및 제품 소개
- 렌더러: `data_storytelling`

## 색상 팔레트

- 배경: #0F1B2D / #1B2F4B
- 전경: #F5F7FA
- 강조: #4FA3FF, #FF6B6B

## 배경 표현

어두운 대시보드

## 재질과 질감

- 질감: grid

## 선과 윤곽선

얇은 차트선

## 조명과 그림자

UI 발광

## 피사체 표현 방식

차트·숫자·그래프

## 카메라 움직임

- 기본 움직임: pan

## 애니메이션 특성

- 스텝 모션: 부드러운 모션

## 장면 전환

- 기본 전환: wipe

## 화면 구성

- 텍스트 배치: in-scene

## 텍스트 표현

- 자막/화면 텍스트는 `in-scene` 위치에 배치한다.

## 효과음 특성

- 프로필: click

## 음악 분위기

- 기본 무드: minimal

## 금지할 시각적 표현

손그림, 질감, 장식 배경

## 최소 구현

`core/render_py.py`의 `data_storytelling` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
