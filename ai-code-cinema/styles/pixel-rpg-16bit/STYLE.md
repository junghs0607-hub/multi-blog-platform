# 16-bit Pixel RPG (16비트 픽셀 RPG)

- 카테고리: 게임 그래픽
- 렌더러: `pixel_rpg_16bit`

## 색상 팔레트

- 배경: #0F380F / #306230
- 전경: #9BBC0F
- 강조: #8BAC0F, #306230

## 배경 표현

픽셀 필드 배경

## 재질과 질감

- 질감: pixel

## 선과 윤곽선

픽셀 계단

## 조명과 그림자

플랫

## 피사체 표현 방식

픽셀 캐릭터·타일

## 카메라 움직임

- 기본 움직임: pan

## 애니메이션 특성

- 스텝 모션: 8fps

## 장면 전환

- 기본 전환: cut

## 화면 구성

- 텍스트 배치: in-scene

## 텍스트 표현

- 자막/화면 텍스트는 `in-scene` 위치에 배치한다.

## 효과음 특성

- 프로필: retro

## 음악 분위기

- 기본 무드: playful

## 금지할 시각적 표현

부드러운 곡선, 그라데이션, 고해상도

## 최소 구현

`core/render_py.py`의 `pixel_rpg_16bit` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
