# Crayon Picture Book (크레용 그림책)

- 카테고리: 손그림과 회화
- 렌더러: `crayon_book`

## 색상 팔레트

- 배경: #FFF6E5 / #F5E6C8
- 전경: #3A2E1E
- 강조: #E4572E, #2E86AB

## 배경 표현

따뜻한 종이 배경에 크레용 질감

## 재질과 질감

- 질감: crayon

## 선과 윤곽선

두껍고 거친 손그림 선

## 조명과 그림자

부드러운 낮Note 조명

## 피사체 표현 방식

단순한 둥근 피사체

## 카메라 움직임

- 기본 움직임: push_in

## 애니메이션 특성

- 스텝 모션: 부드러운 모션

## 장면 전환

- 기본 전환: dissolve

## 화면 구성

- 텍스트 배치: bottom

## 텍스트 표현

- 자막/화면 텍스트는 `bottom` 위치에 배치한다.

## 효과음 특성

- 프로필: soft

## 음악 분위기

- 기본 무드: playful

## 금지할 시각적 표현

사실적 렌더링, 날카로운 직선, 네온 색상

## 최소 구현

`core/render_py.py`의 `crayon_book` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
