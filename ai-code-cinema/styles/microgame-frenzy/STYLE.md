# Microgame Frenzy (마이크로게임 프렌지)

- 카테고리: 게임 그래픽
- 렌더러: `microgame_frenzy`

## 색상 팔레트

- 배경: #111111 / #222222
- 전경: #FFFFFF
- 강조: #FFD23F, #FF4D6D

## 배경 표현

빠르게 바뀌는 단색

## 재질과 질감

- 질감: none

## 선과 윤곽선

굵은 플랫

## 조명과 그림자

플랫

## 피사체 표현 방식

미니게임 조각

## 카메라 움직임

- 기본 움직임: pan

## 애니메이션 특성

- 스텝 모션: 12fps

## 장면 전환

- 기본 전환: cut

## 화면 구성

- 텍스트 배치: in-scene

## 텍스트 표현

- 자막/화면 텍스트는 `in-scene` 위치에 배치한다.

## 효과음 특성

- 프로필: pop

## 음악 분위기

- 기본 무드: playful

## 금지할 시각적 표현

느린 전개, 여백, 파스텔

## 최소 구현

`core/render_py.py`의 `microgame_frenzy` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
