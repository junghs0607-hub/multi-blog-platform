# Game Show Flat (게임쇼 플랫 그래픽)

- 카테고리: 게임 그래픽
- 렌더러: `game_show_flat`

## 색상 팔레트

- 배경: #1B2A6B / #2E4BA8
- 전경: #FFFFFF
- 강조: #FFD23F, #FF4D6D

## 배경 표현

무대 배경

## 재질과 질감

- 질감: none

## 선과 윤곽선

굵은 플랫

## 조명과 그림자

스포트라이트

## 피사체 표현 방식

패널·점수판

## 카메라 움직임

- 기본 움직임: pan

## 애니메이션 특성

- 스텝 모션: 부드러운 모션

## 장면 전환

- 기본 전환: wipe

## 화면 구성

- 텍스트 배치: in-scene

## 텍스트 표현

- 자막/화면 텍스트는 `in-scene` 위치에 배치한다.

## 효과음 특성

- 프로필: pop

## 음악 분위기

- 기본 무드: bright

## 금지할 시각적 표현

어두운 톤, 질감, 세밀

## 최소 구현

`core/render_py.py`의 `game_show_flat` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
