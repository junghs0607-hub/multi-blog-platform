# HD-2D (HD-2D)

- 카테고리: 게임 그래픽
- 렌더러: `hd_2d`

## 색상 팔레트

- 배경: #1A2238 / #2E3A5C
- 전경: #F5E9D0
- 강조: #FFB347, #4FA3A3

## 배경 표현

입체 광원 배경 + 픽셀

## 재질과 질감

- 질감: mixed

## 선과 윤곽선

픽셀 + 부드러운 빛

## 조명과 그림자

블룸 조명

## 피사체 표현 방식

픽셀 인물 + 3D 배경

## 카메라 움직임

- 기본 움직임: orbit

## 애니메이션 특성

- 스텝 모션: 10fps

## 장면 전환

- 기본 전환: fade

## 화면 구성

- 텍스트 배치: bottom

## 텍스트 표현

- 자막/화면 텍스트는 `bottom` 위치에 배치한다.

## 효과음 특성

- 프로필: retro

## 음악 분위기

- 기본 무드: epic

## 금지할 시각적 표현

플랫 단조, 원색 남용

## 최소 구현

`core/render_py.py`의 `hd_2d` 렌더러가 이 스타일을 실제로 렌더링한다.
팔레트·질감·전환·모션 규
칙을 파라미터로 강제하며, 다른 스타일과 시각적으로 구분된다.
